# Kernel.panic() 🖥️

**Kernel.panic()** é um jogo de aventura e depuração técnica onde você assume o papel de um processo sentinela dentro de um sistema operacional em colapso. Armado com a poderosa **Debugger Gun**, sua missão é navegar por vastos setores corrompidos, enfrentar falhas críticas e restaurar a ordem binária antes que ocorra um Kernel Panic total.

## 🌌 História

No ano de 2026, a Integridade do Kernel foi comprometida. Arquivos vitais foram perdidos no abismo do Heap e bugs monstruosos tomaram conta dos setores de memória. Você foi instanciado como a última linha de defesa: um sentinela capaz de reescrever as propriedades da realidade digital para salvar o sistema de dentro para fora.

## 🛠️ Funcionalidades Principais

- **Mundos Gigantes e Exploráveis:** Navegue por mapas vastos (4000x3000px) com um sistema de câmera dinâmica.
- **Mecânica de Debugger Gun:** Não use balas, use lógica. Recorte (`CUT`) propriedades de um inimigo e cole (`PASTE`) em outro.
- **Terminal de Código Direto:** Digite comandos reais (`speed=0`, `heal`, `dump`) para manipular as entidades do jogo em tempo real.
- **Batalhas de Boss Épicas:** Enfrente processos mestres como o `NULL_MASTER.EXE` e o `PanicCore` em duelos táticos.
- **Sistema de Progressão:** Desbloqueie novas áreas do sistema e acompanhe seu progresso através de salvamentos automáticos.
- **Gráficos Procedurais Modernos:** Visual "cyber-diagnostic" único, gerado inteiramente por código, com efeitos de glitch e neon.
- **Easter Eggs:** Descubra segredos escondidos no terminal (Dica: tente o comando `tron`).

## 🎮 Como Jogar

### Controles Básicos
- **W, A, S, D:** Movimentação de baixo nível.
- **MOUSE:** Clique para selecionar e inspecionar objetos.
- **F11:** Alternar entre Modo Janela e Tela Cheia.

### Debugger Gun
- **[ X ] CUT:** Recorta a propriedade atual do alvo para o seu clipe.
- **[ V ] PASTE:** Cola o valor do clipe no alvo selecionado (causa dano em Bosses!).
- **[ P ] SMART PATCH:** Tenta aplicar um reparo rápido automático (causa Logic Burst em Bosses).
- **[ TAB ]:** Alterna entre os slots de memória A e B da arma.

### Terminal de Comandos [ Tecla C ]
Abra o terminal e digite ordens diretas para o objeto selecionado:
- `freeze` / `unfreeze`: Para ou libera o movimento.
- `kill`: Tenta terminar o processo.
- `teleport x y`: Move o objeto instantaneamente.
- `dump`: Revela todas as propriedades secretas do alvo.

## 🚀 Instalação e Execução

### Pré-requisitos
- Python 3.10 ou superior.
- Biblioteca Pygame (`pip install pygame`).

### Executando o Jogo
1. Clone o repositório ou baixe os arquivos.
2. No terminal, navegue até a pasta do projeto.
3. Execute o comando:
   ```bash
   python main.py
   ```

## 🧠 Filosofia do Projeto
*Kernel.panic()* foi desenvolvido para misturar mecânicas de jogos de ação com a lógica de programação, incentivando o jogador a experimentar e "quebrar" as regras do jogo usando o próprio sistema de propriedades das entidades.
